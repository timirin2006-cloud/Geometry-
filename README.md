# Геометрия 7 класс — первый признак равенства треугольников

Интерактивный учебный сайт для урока по геометрии 7 класса.

## Что внутри

- понятное пошаговое объяснение первого признака равенства треугольников;
- наглядные схемы и выделение главной идеи «две стороны + угол между ними»;
- алгоритм решения задач;
- 6 тренировочных заданий разных типов;
- тест из 8 вопросов по новой теме;
- отдельный тест из 8 вопросов на повторение темы «градусная мера углов»;
- итоговая страница с результатами двух тестов;
- адаптация под телефон, планшет и компьютер;
- работает без сторонних библиотек и без подключения к серверу.

## Файлы

```text
geometry7_first_criterion/

```

## Как открыть

Откройте `index.html` в браузере.

## Как разместить на GitHub Pages

1. Создайте новый репозиторий.
2. Загрузите `index.html` и `README.md` прямо в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе Source выберите **Deploy from a branch**.
5. Branch: `main`, папка: `/ (root)`.
6. Нажмите **Save**.

После публикации GitHub Pages даст ссылку на сайт.
